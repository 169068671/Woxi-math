# 仓库结构说明

编号目录，Obsidian 文件列表按数字排序即使用顺序。

```
Woxi mathmatic平替/
├── 00_HOME/                 首页、索引、标签、本页
├── 01_安装与排障/           安装说明、复制到应用程序、崩溃报告
├── 02_演示/方向导数/        本地 HTML / Python / Woxi 脚本
│     └── vendor/            Three.js，HTML 离线用
├── 03_工作流/               可复用步骤（Windows + 向日葵等）
├── 06_模板/                 新建笔记时复制
├── 07_收件箱/               还没归类的草稿
├── 90_附件/                 图片等二进制
├── 99_归档/                 过期但要留的旧文件
├── venv/                    Python 运行环境（Finder 可见；Obsidian 可忽略）
└── .obsidian/               Obsidian 库配置
```

## 放哪

| 内容 | 放哪 |
|---|---|
| 安装、崩溃、系统路径 | `01_安装与排障` |
| 某一个数学演示的全部文件 | `02_演示/主题名/` |
| 可重复执行的步骤 | `03_工作流` |
| 截图、预览图 | `90_附件` |
| 临时笔记 | `07_收件箱`，整理后再搬走 |

## 笔记格式

- 正式 `.md` 要有 YAML：`title`、`created`、`updated`、`tags`
- 库内用双链 `[[笔记名]]`，不要只丢裸路径
- 标签只用 [[标签索引]] 里已有的，不另起近义词
- `venv/`、`.mplconfig/` 不是笔记，不要链进去
