# 傅立叶学习体系共享术语词典

> 术语按视频中的特定用法整理，并补入下游 skill 所需的严格边界。原始引文与时间戳见 [`candidates/glossary.md`](./candidates/glossary.md)。

| 术语 | 本体系中的定义 | 关键区别 |
|---|---|---|
| 基 / 基函数 | 描述对象的一组坐标方向；函数空间中是函数族 | 正交、归一和完备是三个独立条件 |
| 坐标 / 系数 | 对象在选定基方向上的分量 | 坐标依赖所选基，不是对象的固有数字 |
| 投影 / 分析 | 通过内积取得某个基方向的坐标 | 非正交基不能直接把普通内积当坐标 |
| 线性组合 / 综合 | 用坐标乘基后累加重建对象 | 精确重建还需要完备性和收敛条件 |
| 函数是无穷维向量 | 用函数的全部取值/展开系数作为坐标的结构直觉 | 是函数空间模型，不是把函数字面看成普通无限数组 |
| 函数内积 | 对应函数值乘积的连续加权累加 | 复空间必须按约定对一方取共轭 |
| 复共轭 | 将虚部符号反转，使自内积成为非负实数 | 傅立叶分析核的负号来自这一角色 |
| 积分变换 | 用一族核函数对原函数连续投影 | 变换结果是坐标函数，不是原函数的简单“变形” |
| 线性算子 | 保持加法和数乘结构、作用于函数的运算 | 无限维算子需要定义域与边界条件 |
| 特征函数 | 算子作用后只乘一个标量、形状不变的函数 | `e^{st}` 是求导算子的特征函数 |
| 复指数 | 在复平面匀速旋转、同时编码频率与相位的函数 | 正弦余弦是正负旋转复指数的组合 |
| 正 / 负频率 | 复平面上相反的旋转方向 | 实信号两侧频谱通常共轭配对 |
| 正交归一 | 不同基内积为零且每个基范数为一 | 正交归一仍不自动保证完备 |
| 傅立叶级数 | 周期函数在离散谐波上的坐标展开 | 分析是投影，综合是离散求和 |
| 频谱 / 频域 | 信号在频率基下的坐标函数 | 一般包含幅度和相位，不只是单边幅度图 |
| 基频 / 频率间隔 | 周期 `T` 对应的 `1/T` 频率网格 | 周期越长，频率网格越密 |
| 傅立叶变换 | 非周期/连续频率情形下的分析—综合变换对 | 普通积分不收敛时需 `L²` 或分布框架 |
| 普通频率 `f` / 角频率 `ω` | `f` 用 Hz，`ω=2πf` 用 rad/s | 换变量时必须同步换 `df` 与 `dω` |

## 统一约定

本体系主线使用角频率约定：

```text
F(ω) = ∫ f(t)e^{-jωt}dt
f(t) = (1/2π)∫ F(ω)e^{jωt}dω
```

遇到其他教材时，使用 [`fourier-convention-audit`](./fourier-convention-audit/SKILL.md) 做成对换算，不把单个 `2π` 的位置当成唯一标准。
