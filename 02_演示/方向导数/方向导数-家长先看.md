# 方向导数演示｜家长先看

> [!warning] 这不是中考内容
> 给已经会平面坐标、一次/二次函数的孩子「往后看一眼」。  
> **全部在本机打开、本机改。不要用本机 Woxi Studio**（macOS 26 会崩溃），也不必等在线 Playground。见 [[Woxi Studio macOS 26 渲染Bug分析报告]]。

![[方向导数演示预览_马鞍.png]]

## 打开哪份（都在本地）

1. **推荐：本地 HTML** — 双击 [[打开方向导数HTML.command]] 或 [[方向导数演示.html]]  
   Three.js 已经放在 `vendor/three.min.js`，断网也能开。改这个 html 文件即改演示。
2. **本地 Python** — 双击 [[运行方向导数演示.command]]
3. 可选：本机命令行 `woxi` 跑 [[方向导数演示.wls]]（只出文字，没有滑块图）

## 片子在讲什么

1. 沿单位方向 **u** 走一小步 \(h\)，高度差除以 \(h\)，就是这一段的平均坡度。
2. \(h\) 越来越小，平均坡度逼近瞬时坡度，这就是方向导数。
3. HTML / Python 里可勾选「所有方向」：箭头长短表示 \(|D_u f|\)；白色箭头是增长最快的方向（梯度）。

## 家长只需做的

- 先说：这是爬山时「往这个方向走，高度涨得有多快」。
- 不必布置练习卷，不必打开 Studio，不必等网页加载。
