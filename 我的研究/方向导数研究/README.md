## 知识体系

### 核心概念链

```
偏导数 → 梯度 → 方向导数
  ↓        ↓        ↓
基础方向  最快方向  任意方向
```

### 关键公式

| 概念 | 公式 | 说明 |
|---|---|---|
| 梯度 | $\nabla f = (f_x, f_y)$ | 两个偏导数组成的向量 |
| 最快上升方向 | $\mathbf{u}_{\max} = \frac{\nabla f}{\|\nabla f\|}$ | 梯度单位化 |
| 最大变化率 | $\|\nabla f\|$ | 梯度的模长 |
| 方向导数 | $D_{\mathbf{u}}f = \nabla f \cdot \mathbf{u}$ | 梯度点乘单位方向 |
| 夹角形式 | $D_{\mathbf{u}}f = \|\nabla f\| \cos\theta$ | $\theta$ 为方向与梯度的夹角 |
