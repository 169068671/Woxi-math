# 抽象数学概念可视化讲解工作流

> [!summary] 固定目标
> 把方向导数、极限、梯度、导数、向量、积分等抽象概念，转化为初学者可以按“情境—对象—符号—图示—代入—变化—结论”逐层理解的材料。不能只给公式，也不能用与数学关系不一致的装饰图代替解释。

## 一、先确定讲解对象

开始制作前先回答：

1. 学习者已经知道什么，尚不知道什么？
2. 当前概念研究的是哪个空间、哪个对象和哪个变化？
3. 哪些量是固定的，哪些量由用户选择，哪些量由计算得到？
4. 最容易混淆的对象有哪些？

方向导数示例必须区分：

- 坐标原点 $O=(0,0)$：建立坐标系，不一定是运动起点。
- 移动起点 $P=(1,1)$：本次计算从这里开始。
- 单位方向向量 $\mathbf u$：只规定方向，长度为 $1$。
- 步长 $h$：人为选择的带符号参数。
- 实际位移 $h\mathbf u$：同时包含方向和移动量。
- 实际距离 $\Delta s=\lVert h\mathbf u\rVert=|h|\lVert\mathbf u\rVert$。

## 二、新符号必须就近解释，并链接图片示例

主讲页面不在开头堆放大块符号词典。每个符号第一次出现时，必须在它的公式或解释语句旁边完成最小必要说明，并紧挨着放“看图”链接，跳转到独立的符号图片示例页对应锚点。

每个首次出现的符号至少说明六件事：

1. **名称与读法**：例如 $\theta$ 读 theta，$\Delta$ 读 delta，$\nabla$ 读 nabla。
2. **数学角色**：点、标量、向量、函数、运算符还是极限记号。
3. **直观含义**：例如 $f(x,y)$ 是位置对应的高度。
4. **当前取值**：例如 $P=(1,1)$、$\theta=45^\circ$。
5. **来源**：用户选择、题目给定、定义规定或计算得到。
6. **成立条件**：例如只有 $\lVert\mathbf u\rVert=1$ 且 $h>0$ 时，$h$ 才等于沿 $\mathbf u$ 前进的距离。

符号链接与独立图示页必须满足：

1. 链接放在符号首次出现处，文案简短明确，例如“看 $h$ 的图”“看 $\Delta f$ 的图”。
2. 链接直接跳到具体符号的锚点，不让学习者进入总页后重新寻找。
3. 符号图示必须说明它在当前问题中指向什么，例如点、箭头、角度、距离、高度差或投影关系，不能只重复文字定义。
4. 符号页沿用主页面的颜色、点名、箭头样式和数值，避免形成第二套视觉语言。
5. 每个符号图示都提供返回主讲页面的入口；主讲页面顶部提供符号图片示例总页入口。
6. 同一符号后续再次出现时不必反复插入链接，避免打断计算主线。

> [!warning] 禁止做法
> 不得先展示 $D_{\mathbf u}f(P)=\nabla f(P)\cdot\mathbf u$，再假设初学者自然认识 $D$、下标、$\nabla$、点积和括号中的 $P$。

## 三、用一句自然语言读完整公式

公式必须配一条不省略对象的自然语言：

$$
D_{\mathbf u}f(P)
=\lim_{h\to0}\frac{f(P+h\mathbf u)-f(P)}{h}
$$

读作：

> 从点 $P$ 出发，沿单位方向 $\mathbf u$ 走一个正的小步长 $h$；用新位置的函数值减去起点函数值，再除以实际行走距离；当步长越来越接近零时，这个平均变化率所趋近的值，就是 $f$ 在 $P$ 点沿 $\mathbf u$ 方向的方向导数。

## 四、每一个计算动作配一幅解释图

图示与计算一一对应，推荐顺序如下：

1. **对象定位图**：标清坐标原点、计算起点、坐标轴和定义域。
2. **方向分解图**：用直角三角形解释角度、正弦、余弦和单位向量。
3. **位移图**：从 $P$ 画到 $P+h\mathbf u$，分别标出 $\Delta x$、$\Delta y$ 和实际距离。
4. **函数值图**：把两个输入点对应到函数值或曲面高度，标出 $f(P)$、$f(P+h\mathbf u)$ 和 $\Delta f$。
5. **变化率图**：用坡度三角形展示“纵向变化 ÷ 横向距离”。
6. **极限连续图**：并排画出多个逐渐减小的 $h$，展示割线逼近切线或近似值逼近极限值。
7. **另一种算法核对图**：例如用梯度投影图核对方向导数。

图中的同一对象必须始终使用同一颜色、名称和几何位置逻辑。若图形为了可读性进行了局部放大，必须明确标注“示意放大，不按真实比例”。

“另一种算法核对”只要引入了新概念或新运算，就必须按新知识完整讲解，不能只给核对结果。例如用梯度核对方向导数时，必须依次说明偏导数的含义、两个偏导数的计算、在指定点的代入、梯度向量的组成、点积的逐项相乘与相加，以及结果在图上的投影含义。

## 五、代入计算不得跳步

每个数值例子至少展示：

1. 已知条件。
2. 符号变成具体数值的过程。
3. 新位置或新状态。
4. 原值与新值。
5. 差值。
6. 分母或实际距离。
7. 商、近似值或极限。
8. 最终结论及其自然语言解释。

### 中间公式必须能够向前追溯

任何首次出现的化简式、中间公式或结论式，都必须能从上一条已经解释的式子逐行推导出来。不能因为后续只需要使用结果，就省略它的来源。

逐行推导至少满足：

1. 标明从哪一个已知式开始。
2. 展示代入对象和代入位置。
3. 展开平方、乘法、约分、合并同类项等实际动作。
4. 说明每一步使用的规则和成立条件。
5. 指出容易漏掉的项，例如 $(a+b)^2$ 中的 $2ab$。
6. 最终明确哪些部分保持不变，哪些部分会随参数改变。

例如方向导数示例中，若页面出现

$$
\frac{1}{\sqrt2}+\frac h4,
$$

就必须从 $P+h\mathbf u$ 开始，经过新位置、函数代入、平方展开、函数值作差和除以距离，完整推导到该式；不得直接把它作为“本例平均坡度公式”交给初学者。

必须区分：

- **精确计算值**与**界面显示值**，例如 $0.00795096\approx0.0080$。
- **人为选定参数**与**推导结果**，例如 $h$ 是滑块选择的试验步长，不是函数算出来的。
- **平均值**与**瞬时值**，例如 $0.7099$ 是当前小步的平均坡度，$0.7071$ 是 $h\to0$ 时的方向导数。

## 六、展示“只改变一个变量”的影响

需要解释微小变化时，优先使用：

- 九宫格：固定中心状态，周围八格改变方向或单一条件。
- 并排对照：变化前、变化后、差异。
- 连续小图：$h=0.5,0.1,0.01,\ldots\to0$。
- 实时数值联动：图上的点、箭头、差值和公式同步更新。

每组对照必须明确写出：什么保持不变、什么发生改变、改变后哪个量受到影响。

## 七、主动交代条件与反例

至少检查：

- 参数为正、为负、为零时分别意味着什么。
- 向量是否已经单位化。
- 分母能否为零。
- 极限是否存在；“趋近零”是否被误写成“直接令其等于零”。
- 图示所在空间是否正确，例如二元函数的方向在 $xy$ 定义域平面，而高度变化显示在函数值维度。
- 例子中的选择是否具有特殊性，能否推广到一般情况。

## 八、HTML 默认采用“三页联动”结构

### 实验页面

实验页面负责让学习者先动手观察“某个量发生细小改变时，其他量怎样跟着改变”，不能只作为静态目录页。它与主讲页、符号页共同构成完整交付。

实验页默认包含：

1. **固定对象说明**：明确本轮保持不变的函数、起点或其他条件。
2. **可变参数控件**：根据概念提供方向、步长、位置或其他单变量控件，并标明哪些值是学习者主动选择的。
3. **九宫格或连续小图**：中心格显示当前状态，周围格一次只改变一个方向或条件；不适合九宫格时使用前后对照或连续分镜。
4. **图数联动**：图中的点、箭头、距离和高度变化必须与旁边数值同步。
5. **当前状态读法**：用自然语言说明“从哪里出发、朝哪里、改变了多少、结果怎样”。
6. **进入图算主线的入口**：把当前实验现象带入完整图解计算，而不是让实验页成为孤岛。
7. **符号帮助入口**：实验页出现的陌生符号同样可以链接符号图片示例页。

方向导数实验页推荐用方向九宫格：固定函数与点 $P$，中心显示当前方向，周围八格显示相邻方向；配合步长 $h$ 控件，实时联动 $P+h\mathbf u$、$\Delta f$、$\Delta s$、平均坡度和方向导数。必须明确方向位于 $xy$ 定义域平面，高度变化显示在函数值维度。

### 主讲页面

主讲页面固定使用“大幅解释图 + 对应计算”左右交替的长页面。桌面端左右排列并逐段交替图文位置，窄屏端按“先看图、后计算”纵向排列。默认信息层级：

1. 一句话直觉。
2. 本例已知条件。
3. 图示与计算左右交替的分步故事。
4. 新符号首次出现处的轻量图片链接。
5. 单变量微变化对照。
6. 精度与舍入说明。
7. 边界情况与另一种算法核对。
8. 最终一句话总结。

每一段固定回答四个问题：图上发生了什么、公式正在算什么、数字从哪里来、这一步用自然语言怎么读。方向导数推荐保留五段主线：

1. 俯视地图：定位坐标原点、移动起点和方向。
2. 位移放大图：解释 $h$、$\mathbf u$、$h\mathbf u$ 和新位置。
3. 曲面侧视图：解释原高度、新高度和 $\Delta f$。
4. 坡度三角形：解释 $\Delta f/\Delta s$。
5. 割线趋近切线：解释 $h\to0$ 与方向导数。

### 符号图片示例页

独立符号页按“位置与高度—方向—位移—变化与坡度—极限—梯度核对”分组。每张卡片包含：符号、名称、当前角色、一幅对应图、必要的最短算式和返回主线链接。页面顶部提供锚点导航，主讲页的符号链接必须直接落到相应卡片。

### 三页之间的导航关系

- 实验页 → 主讲页：从现象进入一次完整计算。
- 主讲页 → 实验页：返回改变方向、步长或其他变量继续观察。
- 主讲页、实验页 → 符号页锚点：查询首次出现的新符号。
- 符号页 → 主讲页：看完符号后回到推导主线。

三页的导航文案必须说明目的，例如“用九宫格继续实验”“一边看图，一边把数字算出来”“看 $h$ 的图片示例”，不能只写含义不明的“下一页”。

### 完全离线要求

三页必须能够在无网络环境下直接双击本地HTML运行：

1. HTML、CSS和JavaScript优先内嵌，或使用同一交付目录中的本地相对路径。
2. 图示优先使用内嵌SVG、Canvas或本地图片；不得引用远程图片地址。
3. 不依赖CDN、在线字体、在线公式渲染器、分析脚本、网络接口或需要登录的资源。
4. 页面之间使用相对路径和锚点跳转，移动整个交付文件夹后仍应有效。
5. 如确需第三方库，必须把可离线运行的版本一并放入交付目录，并在页面中使用相对路径引用。
6. 交互计算在浏览器本地完成，不把学习者输入发送到网络。

数学图示优先使用可缩放SVG、Canvas或可交互图形，保证离线清晰；图中文字和公式应保持可选择、可缩放，不把主要教学内容压进一张不可编辑的截图。

## 九、交付前强制检查

- [ ] 每个新符号都已解释名称、含义、当前值和来源。
- [ ] 已交付实验页、图算主讲页和符号图片示例页，三者均可离线打开。
- [ ] 页面源码不包含CDN、远程图片、在线字体、在线公式渲染器或网络接口依赖。
- [ ] 三页使用本地相对路径互相跳转，移动整个文件夹后链接仍然成立。
- [ ] 断网后直接双击实验页，图示、计算、控件、锚点和三页导航仍可使用。
- [ ] 实验页清楚区分固定量、可变量和计算结果，并至少提供一种单变量微变化对照。
- [ ] 实验页的图形与数值随同一个参数同步变化。
- [ ] 三页之间都有含义明确的双向导航入口，没有孤立页面。
- [ ] 每个新符号第一次出现处都有直达对应图片示例的轻量链接。
- [ ] 主讲页面没有用大块符号词典打断图算主线。
- [ ] 符号图片示例页的每张卡片都有图示、对应锚点和返回主线入口。
- [ ] 主页面与符号页使用同一套颜色、点名、箭头和数值。
- [ ] 坐标原点、计算起点、终点和方向没有混淆。
- [ ] 人为选择的参数没有被描述成计算结果。
- [ ] 向量、标量、长度和方向使用了准确措辞。
- [ ] 每个关键计算动作都有对应图示。
- [ ] 图示与公式中的点、方向、颜色和数值一致。
- [ ] 中间计算没有跳步。
- [ ] 未舍入值与显示近似值已经区分。
- [ ] 平均变化率与瞬时变化率已经区分。
- [ ] 正负参数、单位化和极限条件已经说明。
- [ ] 初学者仅阅读本页即可知道公式怎么读、数字从哪里来、图在表达什么。
- [ ] 每个首次出现的中间公式都能向前追溯到已经解释的已知式，没有突然出现的结果。
- [ ] 另一种算法核对没有省略新概念、运算规则、逐项代入或几何含义。
- [ ] 用户指出的局部疑难点已有明确入口、针对性解释和返回原位置的链接。

任何一项未通过时，不得宣布数学概念讲解页面完成。

## 十、局部疑难点详细解释页与理解确认闭环

当学习者已经理解主线的大部分内容，只指出某一幅图、某一步计算或某一种核对方法不明白时，优先新建独立的“疑难点详细解释页”，不要把整个主讲页面无限加长，也不要让学习者重新阅读已经掌握的内容。

疑难点页面必须：

1. **只补讲指定疑难点**：页面开头明确本页解决哪些问题，不重复整套课程。
2. **恢复被省略的来源链**：从学习者最后看懂的一步开始，逐行推到不懂的式子。
3. **图与算式逐项对应**：图中的点、线、方向、距离和变化量必须能在旁边找到对应算式。
4. **加入单变量交互**：适合时提供滑块、方向按钮或连续小图，只改变一个变量，实时更新图形与数值。
5. **解释错误路径**：主动说明为什么不能直接代入零、为什么不能使用已舍入值继续算、为什么不能省略中间项等。
6. **完整讲解核对算法**：若疑难点涉及梯度、点积或另一种方法，必须从定义和最基础运算开始，不假设学习者已经会。
7. **双向精确导航**：原主讲页在疑难点旁提供直达入口；疑难页提供返回原位置的链接，而不是只返回页面顶部。
8. **保持视觉语义一致**：沿用原主讲页的颜色、点名、数值和符号图片链接。
9. **继续满足离线要求**：HTML、SVG、CSS 和 JavaScript 均使用内嵌内容或本地相对路径。

### 理解确认闭环

疑难页完成后，不能只以“页面已生成”作为教学完成标准。应让学习者实际查看，并根据反馈继续修正：

- 仍有不懂：记录具体图、具体算式或具体词句，继续做针对性补讲。
- 已经看懂：把本次有效的解释结构写回工作流，作为以后同类概念的默认检查项。
- 尚未获得反馈：只能标记为“页面已交付，理解效果待确认”，不得声称学习者已经掌握。
