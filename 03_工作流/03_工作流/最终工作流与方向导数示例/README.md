# 最终工作流与方向导数示例包

本文件夹集中保存已经定稿的抽象数学概念可视化讲解工作流，以及按该工作流制作的方向导数三页联动示例。

## 内容

- `01_最终工作流/抽象数学概念可视化讲解工作流.md`：最终工作流。
- `02_方向导数示例/方向导数本次数值代入详解.html`：图算主讲页，默认从这里开始。
- `02_方向导数示例/方向导数计算五与梯度详细解释.html`：针对计算五、图五和梯度核对的疑难点详细解释页。
- `02_方向导数示例/方向导数九宫格详解.html`：实验页，用于改变方向和步长、观察数值变化。
- `02_方向导数示例/方向导数符号图片示例.html`：符号图片示例页。

## 使用

直接双击 `02_方向导数示例/方向导数本次数值代入详解.html`，先沿主线理解一次完整推导；需要观察方向或步长变化时，再进入九宫格实验页。三个 HTML 使用相对路径互相跳转，内容均内嵌，可离线使用。

## 归集口径

本包只纳入最终交付文件。旧版 Notebook、Python/Wolfram/GeoGebra 脚本、启动器、早期单页演示和设计过程稿继续保留在原目录，不并入本包。
